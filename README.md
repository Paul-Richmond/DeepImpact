# DeepImpact
Apply computational methods in order to gauge the societal impact of fundamental science discoveries.


# Setup
I'm assuming that you have conda installed on your machine, if not see [here](https://docs.conda.io/projects/conda/en/stable/). 
After cloning this repository use the terminal to cd into the repository and then use:

`conda env create -n DeepImpact --file environment.yml`

to create a new conda environment called *DeepImpact* with all the necessary packages installed.
